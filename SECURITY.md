# Security Policy

## Reporting a Vulnerability

If you find a security issue in The Baseline, please report it privately rather than opening a public issue. Use GitHub's private vulnerability reporting on this repository — **Security tab → Report a vulnerability** (the feature is enabled here).

Please include:

- A description of the issue and its potential impact
- Steps to reproduce
- Any relevant logs or screenshots

We'll acknowledge reports within a reasonable timeframe and keep you updated as we investigate and fix confirmed issues.

## Scope

This covers the Worker (`src/index.js` and its routes), the client application, and the self-published feed endpoints. It does not cover third-party RSS sources aggregated by the site.
